BUILD OPTIONS
═══════════════════════════════════════════════════════════════════════════════

CURRENT (Vulkan only):
  cmake .. (no flags)
  Result: Vulkan-only GPU acceleration

ADD OPENCL STATIC:
  cmake .. -DGGML_OPENCL=ON -DGGML_OPENCL_USE_ADRENO_KERNELS=ON
  Result: OpenCL built into main library, kernels embedded

ADD OPENCL DYNAMIC:
  cmake .. -DGGML_OPENCL=ON -DGGML_BACKEND_DL=ON
  Result: Separate libggml-opencl.so, loaded at runtime

ADRENO OPTIMIZATION (Snapdragon):
  cmake .. -DGGML_OPENCL=ON -DGGML_OPENCL_USE_ADRENO_KERNELS=ON
  Result: Detects Adreno GPU, uses optimized kernels

WHEN TO USE WHAT
═══════════════════════════════════════════════════════════════════════════════

USE VULKAN (Current):
  ✓ Already working
  ✓ Optimized for your architecture
  ✓ No additional compilation needed

ADD OPENCL STATIC:
  If: You want CPU+GPU hybrid inference
  If: Multi-GPU support needed
  Not recommended: Adds binary size, compilation time

ADD OPENCL DYNAMIC:
  If: You want runtime GPU selection
  If: Reduce binary size for CPU-only variants
  Benefit: Load only when needed

USE FALLBACK/STUB:
  If: OpenCL support removed, but code still references it
  If: You want graceful degradation (falls back to CPU)
  Benefit: Code compatibility without actual implementation
